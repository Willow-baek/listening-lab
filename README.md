# Listening Lab

Live site: https://willow-baek.github.io/listening-lab/

## GitHub Pages

Pushes to `main` run the tests and publish via GitHub Actions. `npm run build:pages` builds for the `/listening-lab/` URL path.

GitHub Pages is static hosting. The verified ABC neighbours and Small talk videos include saved timed captions. For other videos, paste a transcript with timestamps or import an SRT/VTT file. Live caption fetching is available only with the development server or a separately hosted backend.

Session records stay in each browser and are separate from localhost and the earlier Sites URL. The total elapsed timer includes pauses; only the stage timer pauses.

React + TypeScript로 만든 브라우저 로컬 리스닝 훈련 앱입니다. 기존 프로젝트가 없어 이 폴더에 독립적인 MVP로 구현했습니다.

## 사용 흐름과 구현

1. ChatGPT에서 고른 YouTube 링크와 2초 이상의 구간만 입력합니다. STEP 1을 마친 뒤 STEP 2에서 처음 스크립트를 붙여넣습니다. 입력 전에는 STEP 2에 ‘스크립트 입력 대기’를 표시합니다. 입력 후 ‘스크립트 공부 시작’을 눌러야 타이머가 흐르며, 스크립트 없이 다음 단계로 넘어갈 수 없습니다. 기본 예시 구간은 40초입니다. 40초 이하는 총 60분을 배분하고, 초과 시 나머지 네 단계에 총 40분을 확보하면서 반복 시간을 더합니다. 긴 구간은 전체 진행 또는 두 세션으로 나누기를 선택합니다.
2. First Listening → Transcript Study → Listening × 10 세 번 → Difficult Parts → Shadowing의 순서를 유지합니다.
3. 공식 YouTube 플레이어를 표시합니다. 실제 PLAYING 상태와 재생 위치의 연속적인 진행을 확인해 반복을 계산하며 버퍼링과 앞으로 건너뛰기는 완료 횟수로 인정하지 않습니다. 반복 단계는 실제 10회 후 멈추며, 학습자가 다음 단계로 버튼을 눌러 이동합니다. 단계 전환 시 자동 재생을 시도하고, 브라우저가 차단하면 재생 버튼을 안내합니다.
4. 일시정지는 재생과 타이머를 함께 멈춥니다. 다른 탭으로 이동하면 일시정지됩니다. 스크립트 공부와 어려운 표현 검토 시간은 오디오 없이도 흐릅니다. 각 단계에서 2분을 추가할 수 있습니다.
5. 최초 듣기 기록, 스크립트 텍스트 선택으로 어려운 표현 표시, 메모 수정·삭제, 이해 완료 표시, 수동 구간 반복을 지원합니다. 모바일에서는 표현을 직접 입력해 표시할 수 있습니다.
6. STEP 7 뒤에는 별도의 **최종 평가 화면**이 나옵니다. 8번째 훈련 단계가 아닙니다. 훈련 시간은 이 시점에 확정되어 평가 작성 시간이 포함되지 않습니다.
7. 다섯 문항에 답합니다. Before & After 비교 화면은 사용자 요청으로 제거했습니다. 답변과 평가 초안은 새로고침 후 복원됩니다. 자동 정확도 점수는 산출하지 않습니다.
8. 결과에는 실제 훈련 시간·반복 횟수·난이도 추천·추천 이유·다음 자료 선택 가이드를 표시합니다. 결과 애니메이션은 reduced-motion 설정을 존중합니다.
9. START NEXT SESSION은 빈 YouTube 입력 화면으로 돌아갑니다. 완료된 결과는 학습 기록에 남으며 응답까지 다시 볼 수 있습니다. 기록 내려받기는 사용자 요청으로 제거했습니다.

## 추천 규칙

| 결과 | 조건 (모두 충족) |
| --- | --- |
| LEVEL UP | 스크립트 대부분/충분히 이해 + 반복 후 거의 모두 들림 + 남은 어려움 거의 없음 + 난이도 적절/쉬움 |
| LEVEL DOWN | 스크립트 이해 어려움 + 반복 후 일부 표현 이하만 들림 + 상당한 어려움 남음 + 난이도 어려움 |
| KEEP LEVEL | 그 밖의 모든 조합. 응답이 서로 엇갈리는 경우 포함 |

처음 듣기 응답은 향상에 관한 설명에만 사용하며 UP/DOWN 자격을 결정하지 않습니다. 첫 듣기를 못했다는 이유만으로 DOWN이 나오지 않습니다. 규칙은 `src/domain.ts`에 있고 AI·API 키가 필요하지 않습니다. 추천은 객관적 능력 평가가 아닌 자기평가 기반 자료 선택 가이드입니다. 다음 자료는 사용자가 ChatGPT에서 직접 선택합니다.

## 저장

`localStorage` 키 `listening-lab.active.v1`에 진행 중 훈련과 최종 평가 초안을, `listening-lab.history.v1`에 완료 결과·응답을 저장합니다. `listening-lab.pending.v1`에는 나눈 뒤 이어갈 구간을 저장합니다. 훈련 복원은 항상 일시정지 상태입니다. 로그인/클라우드 전송은 없습니다. 같은 기기라도 브라우저와 origin(호스트·포트)이 다르면 기록이 분리됩니다. 저장 공간 부족·저장 차단 시 경고와 다시 저장 버튼을 표시합니다. 브라우저 데이터를 지우면 로컬 기록도 지워지므로 필요한 결과는 내려받으세요.

시작 화면의 소개 문구·장식은 제거했습니다. 보조 설명은 기능 옆 물음표로 옮겼으며 마우스 올리기, 클릭·터치, 키보드 포커스로 열립니다. 다시 누르기·바깥 선택·Esc로 닫을 수 있습니다. 모바일 화면 경계 안에 표시되며 오류·입력 제한·핵심 학습 지시는 계속 표시합니다. 브라우저에서 데스크톱/모바일 표시, 키보드 열기, Esc, 바깥 클릭, 재클릭 닫기를 확인했습니다.

## 긴 구간과 두 세션으로 나누기

총시간 = `max(60분, 구간 길이 × 30회 + 40분)`입니다. 40초는 고정 길이 제한이 아니라 이 시간 배분 정책의 기준점입니다. 60초는 70분, 120초는 100분입니다. 나머지 네 단계는 최소 6분/14분/10분/10분을 확보합니다.

40초를 넘는 구간에는 전체/두 세션 선택이 나타납니다. 두 세션은 원래 구간의 중간 초에서 나누며, 홀수 길이도 겹침·빈 구간 없이 연결합니다. 2분을 나누면 1분씩 두 세션, 각 70분, 총 140분입니다. 각 세션은 독립적인 7단계·30회 반복·최초 기록·STEP 2 스크립트·평가·결과를 갖습니다.

첫 세션 결과에서 다음 구간을 바로 시작할 수 있습니다. 새 자료로 시작을 선택해도 대기 구간은 시작 화면에 보존됩니다. 실제로 새 훈련을 시작하면 대기 구간을 새 계획으로 교체한다는 안내를 표시합니다. 완료 기록은 유지됩니다.

빌드 및 테스트 12개 통과. 브라우저에서 2:00~4:00을 2:00~3:00과 3:00~4:00으로 나누는 계획, 첫 구간 생성·복원, 최종 평가 후 대기 구간 보존·이어서 시작, 두 번째 구간의 빈 기록·0회 카운트와 새로고침 복원을 확인했습니다. 완료 전환은 개발 전용 `tests/split.html` fixture로 검증했습니다. 실제 70~100분 전체 재생은 실행하지 않았습니다.

## YouTube 재생 주소 수정

로컬 실행은 **http://localhost:5176/** 를 사용하세요. 같은 ABC 영상이 숫자 주소 `127.0.0.1`에서 오류 150을 내지만 localhost에서는 실제 재생되는 환경을 확인했습니다. 숫자 주소로 앱을 열면 Vite의 로컬 임시 이전 경로로 진행 중 세션·완료 기록·대기 구간을 전달한 뒤 localhost로 연결합니다. 원래 주소의 저장 데이터는 남겨 둡니다. 이전 localhost 데이터도 `listening-lab.localhost-backup.v2`에 보관합니다.

이전 내용은 URL이나 파일에 기록하지 않으며 로컬 개발 서버 메모리에만 최대 60초 보관합니다. UUID 토큰은 한 번만 사용할 수 있고, 출처·전달 키를 제한합니다. 이미 이전한 주소를 다시 열 때는 오래된 원본으로 덮어쓰지 않습니다. Vite dev/preview에서만 이 로컬 이전 기능이 동작합니다. 실제 HTTPS 배포 주소는 변경하지 않습니다.

공식 iframe의 referrer policy와 재생 권한을 명시했습니다. 재생 오류에는 오디오 단계의 타이머와 재생 제어를 멈추고 다시 불러오기 버튼을 제공합니다. 스크립트 공부·어려운 표현 검토 단계의 타이머는 영상 로딩과 독립적으로 동작합니다. 자동재생 차단은 실제 재생 오류와 분리하여 플레이어에서 직접 재생할 수 있도록 했습니다. 콘텐츠 소유자가 실제로 삽입을 금지한 영상은 이 수정으로 제한을 해제할 수 없습니다.

검증: 빌드 및 14개 테스트 통과. 로컬 이전 API의 외부 출처 차단·잘못된 데이터 거부·일회성 토큰을 별도로 확인했습니다. 사용자와 동일한 ABC 영상 및 8~48초 구간이 앱 안에서 재생되고 진행되는 것을 브라우저에서 확인했습니다.

## STEP 2 타이머 수정

스크립트가 비어 있으면 ‘스크립트 입력 대기’와 입력 안내를 표시합니다. 스크립트 입력 뒤 ‘스크립트 공부 시작’을 누르면 영상이 멈췄거나 로딩에 실패해도 공부 시간이 흐릅니다. 일시정지 및 다른 탭으로 이동하면 타이머가 멈춥니다. 브라우저에서 영상이 정지된 채 14:00에서 13:40으로 감소하는 것을 확인했습니다. 관련 회귀 테스트를 포함하여 총 15개 테스트와 빌드가 통과했습니다.

## 최신 훈련 화면 변경

- 상단의 재생/일시정지 버튼은 페이지 맨 아래의 공식 YouTube 플레이어를 제어합니다. 영상은 CSS로 숨기거나 가리지 않습니다. 반복 화면은 횟수와 남은 시간을 크게 표시합니다.
- STEP 3~5는 각 10회에서 정지하고 사용자가 ‘다음 단계로’를 눌러 이동합니다. STEP 6도 시간이 끝나면 정지하며 수동으로 넘어갑니다.
- 반복 사이 휴식은 기본 3초이고 없음/2초/3초/5초로 변경할 수 있습니다. 휴식 중에는 영상·훈련 시간이 멈추고, 일시정지 시 휴식 카운트다운도 멈춥니다. 휴식은 예상 훈련 시간에 별도로 추가됩니다. 마지막 10회 후에는 자동 재생하지 않습니다.
- STEP 2의 스크립트 가져오기는 저장된 검증 자막 → 공개 YouTube 영어 시간 자막 조회 → ABC 공식 원문 순서로 시도합니다. 이웃 대화와 Small talk는 실제 유튜브 시간 자막이 포함되어 있습니다. Getting a refund와 다른 ABC 페이지는 시간 자막 조회 실패 시 원문으로 대체됩니다. ABC URL은 HTTPS Learn English 경로만 허용합니다.
- 시간 자막은 텍스트와 별도로 로컬 저장되며 STEP 6에서 문장 재생과 드래그 구간 시간 연결에 쓰입니다. 자동 조회는 비공식 공개 자막 경로라 성공을 보장하지 않습니다. 실패해도 시간 표시가 있는 유튜브 스크립트 붙여넣기 또는 SRT·VTT 파일 입력으로 진행할 수 있습니다. ABC 원문에는 시간이 없으며 추정하지 않습니다. 입력한 스크립트는 자동 가져오기로 덮어쓰지 않습니다. Vite dev/preview 서버가 필요합니다.
- 첫 번째 자기평가는 25% 미만/25~49%/50~74%/75~89%/90~100%의 5개 선택지입니다. 비율은 자기평가 기준이며 자동 점수가 아닙니다. 기존 기록의 4점 척도 의미는 유지합니다.
- Before & After 칸과 기록 내려받기 버튼은 제거했습니다. STEP 1 최초 듣기 메모와 로컬 학습 기록은 유지합니다.

검증: 빌드 및 19개 테스트 통과. 테스트 포트 5178의 격리된 fixture에서 실제 ABC 영상으로 9회 후 3초 휴식, 10회 후 STEP 3 유지, 다음 단계 버튼으로 STEP 4 이동을 확인했습니다. 공식 원문 가져오기를 브라우저와 서버에서 확인했고, 평가 5개 선택지·비교 칸 없음·다운로드 없음과 모바일 화면을 확인했습니다. 전체 30회 장시간 재생 검증은 별도입니다.


기본 구간은 시간 자막의 첫 대사부터 40초입니다(확인 가능한 영상에 한함). 음악 표시 자막은 건너뛰고, 사용자가 직접 고친 구간은 덮어쓰지 않습니다. 첫 대사 시간을 가져올 수 없는 영상은 기본값을 유지하며 직접 시작·종료 시간을 정할 수 있습니다.

STEP 7도 STEP 6과 같은 시간 자막 컴포넌트를 사용합니다. 학습 구간 안의 문장만 표시하며, 문장을 누르면 해당 자막의 시작·종료 시간으로 반복해 섀도잉할 수 있습니다. 시간이 없는 원문은 수동 지정 기능을 유지합니다.


배포는 Sites Worker에서 React 정적 파일과 자막·시작 구간 API를 함께 제공합니다. `npm run build:hosted`로 `dist/server/index.js`를 만들며 API가 로컬 Vite에 의존하지 않습니다. 새 URL은 별도 브라우저 저장 공간을 사용하므로 localhost 기록은 로컬에 그대로 남습니다. 배포 기본 접근 범위는 소유자 전용입니다.
